# ULUÇEEİT - Bursa Uludağ Üniversitesi Web Sitesi

Bursa Uludağ Üniversitesi Çalışma Ekonomisi ve Endüstri İlişkileri Topluluğu resmi web sitesi kaynak kodları.

## 🚀 Hızlı Başlangıç

### 1. Yerel Olarak Çalıştırma
```bash
npm run dev
# veya
npm start
```
Tarayıcınızda `http://localhost:3000` adresini açarak siteyi önizleyebilirsiniz.

### 2. GitHub'a Tek Komutla Otomatik Push (Yükleme)
```bash
npm run push
```
*(İlk kullanımda `.env` dosyanıza `GITHUB_TOKEN=ghp_...` eklemeniz veya komutla token göndermeniz yeterlidir).*
